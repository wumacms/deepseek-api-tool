### 一、极限与连续

#### 1. 两个重要极限
- **第一个**：$\lim_{x \to 0} \frac{\sin x}{x} = 1$
- **第二个**：$\lim_{x \to \infty} (1 + \frac{1}{x})^x = e$ 或 $\lim_{x \to 0} (1 + x)^{\frac{1}{x}} = e$

#### 2. 等价无穷小（当 $x \to 0$ 时，$x \sim \sin x \sim \tan x \sim \arcsin x \sim \arctan x \sim \ln(1+x) \sim e^x - 1$）
- $1 - \cos x \sim \frac{1}{2}x^2$
- $(1+x)^a - 1 \sim ax$
- $\log_a(1+x) \sim \frac{x}{\ln a}$

#### 3. 常用求导公式（基础中的基础）
- $(x^n)' = nx^{n-1}$
- $(e^x)' = e^x$；$(a^x)' = a^x \ln a$
- $(\ln x)' = \frac{1}{x}$；$(\log_a x)' = \frac{1}{x \ln a}$
- $(\sin x)' = \cos x$；$(\cos x)' = -\sin x$
- $(\tan x)' = \sec^2 x$；$(\cot x)' = -\csc^2 x$
- $(\sec x)' = \sec x \tan x$；$(\csc x)' = -\csc x \cot x$
- $(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$
- $(\arccos x)' = -\frac{1}{\sqrt{1-x^2}}$
- $(\arctan x)' = \frac{1}{1+x^2}$

### 二、导数与微分

- **莱布尼茨公式**（高阶导数）：$(uv)^{(n)} = \sum_{k=0}^n C_n^k u^{(n-k)} v^{(k)}$
- **隐函数求导**：等式两边对 $x$ 求导，将 $y$ 视为 $x$ 的函数。
- **参数方程求导**：$\frac{dy}{dx} = \frac{dy/dt}{dx/dt}$

---

### 三、积分

#### 1. 不定积分（基本积分表）
- $\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$
- $\int \frac{1}{x} dx = \ln |x| + C$
- $\int e^x dx = e^x + C$；$\int a^x dx = \frac{a^x}{\ln a} + C$
- $\int \sin x dx = -\cos x + C$；$\int \cos x dx = \sin x + C$
- $\int \sec^2 x dx = \tan x + C$；$\int \csc^2 x dx = -\cot x + C$
- $\int \sec x \tan x dx = \sec x + C$；$\int \csc x \cot x dx = -\csc x + C$
- $\int \frac{1}{\sqrt{1-x^2}} dx = \arcsin x + C$
- $\int \frac{1}{1+x^2} dx = \arctan x + C$

#### 2. 积分方法
- **换元积分法**：第一类换元（凑微分）$\int f[\varphi(x)] \varphi'(x) dx = \int f(u) du$；第二类换元（如三角代换 $\sqrt{a^2 - x^2} \Rightarrow x = a \sin t$）
- **分部积分法**：$\int u dv = uv - \int v du$（口诀：**反对幂指三**，优先将指数/三角函数移入 $dv$）

#### 3. 定积分
- **牛顿-莱布尼茨公式**：$\int_a^b f(x) dx = F(b) - F(a)$，其中 $F'(x) = f(x)$
- **微积分基本定理**：$\frac{d}{dx} \int_a^x f(t) dt = f(x)$（变上限积分求导）
- **对称性**：若 $f(x)$ 为奇函数，$\int_{-a}^a f(x) dx = 0$；若为偶函数，$\int_{-a}^a f(x) dx = 2\int_0^a f(x) dx$
- **华里士（Wallis）公式**（0 到 π/2 的 sin/cos 高次幂积分）：$\int_0^{\pi/2} \sin^n x dx = \int_0^{\pi/2} \cos^n x dx = \begin{cases} \frac{(n-1)!!}{n!!} \cdot \frac{\pi}{2}, & n \text{为偶数} \\ \frac{(n-1)!!}{n!!}, & n \text{为奇数} \end{cases}$

#### 4. 反常积分
- 积分区间无界或积分函数无界，通过极限定义判断收敛性（如 $\int_1^\infty \frac{1}{x^p} dx$ 在 $p > 1$ 时收敛）。

### 四、多元函数微积分

#### 1. 偏导数
- $f_x(x, y) = \frac{\partial f}{\partial x}$，全微分 $dz = \frac{\partial z}{\partial x} dx + \frac{\partial z}{\partial y} dy$
- **隐函数定理**：$F(x, y, z) = 0$，则 $\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}$，$\frac{\partial z}{\partial y} = -\frac{F_y}{F_z}$

#### 2. 二重积分
- **直角坐标**：$\iint_D f(x, y) dxdy = \int_a^b dx \int_{y_1(x)}^{y_2(x)} f(x, y) dy$
- **极坐标**：$\iint_D f(r\cos\theta, r\sin\theta) r dr d\theta$

#### 3. 三重积分
- 直角坐标、柱面坐标（$x = r\cos\theta, y = r\sin\theta, z = z$，体积元 $= r dr d\theta dz$）
- 球面坐标（$x = r\sin\phi\cos\theta, y = r\sin\phi\sin\theta, z = r\cos\phi$，体积元 $= r^2 \sin\phi dr d\phi d\theta$）

#### 4. 曲线积分与曲面积分
- **第一类曲线积分**（对弧长）：$\int_L f(x,y) ds = \int_a^b f[x(t), y(t)] \sqrt{[x'(t)]^2 + [y'(t)]^2} dt$
- **第二类曲线积分**（对坐标）：$\int_L P dx + Q dy = \int_a^b [P x'(t) + Q y'(t)] dt$
- **格林公式**（连通平面区域）：$\iint_D (\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}) dxdy = \oint_L P dx + Q dy$
- **高斯公式**（空间区域）：$\iiint_\Omega (\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}) dV = \oiint_\Sigma (P dy dz + Q dz dx + R dx dy)$
- **斯托克斯公式**（曲面边界）：$\iint_\Sigma (\frac{\partial R}{\partial y} - \frac{\partial Q}{\partial z}) dy dz + (\frac{\partial P}{\partial z} - \frac{\partial R}{\partial x}) dz dx + (\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}) dx dy = \oint_\Gamma P dx + Q dy + R dz$

### 五、无穷级数

#### 1. 常数项级数审敛法
- **正项级数**：比较判别法、比值判别法（$\lim_{n \to \infty} \frac{u_{n+1}}{u_n} = \rho$，$\rho < 1$ 收敛，$\rho > 1$ 发散）
- **交错级数**：莱布尼茨判别法（$u_n$ 单调减且 $\lim u_n = 0$ 则收敛）
- **绝对收敛与条件收敛**：$\sum |u_n|$ 收敛则原级数绝对收敛；原级数收敛但 $\sum |u_n|$ 发散则条件收敛。

#### 2. 幂级数
- **收敛半径**：$R = \frac{1}{\limsup \sqrt[n]{|a_n|}} = \frac{1}{\lim |\frac{a_{n+1}}{a_n}|}$
- **展开式**（常见麦克劳林级数）：
  - $e^x = \sum_{n=0}^\infty \frac{x^n}{n!}, \quad x \in \mathbb{R}$
  - $\sin x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n+1}}{(2n+1)!}, \quad x \in \mathbb{R}$
  - $\cos x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n}}{(2n)!}, \quad x \in \mathbb{R}$
  - $\frac{1}{1-x} = \sum_{n=0}^\infty x^n, \quad |x| < 1$
  - $\ln(1+x) = \sum_{n=1}^\infty (-1)^{n-1} \frac{x^n}{n}, \quad -1 < x \leq 1$

#### 3. 傅里叶级数
- 周期为 $2\pi$ 的函数 $f(x)$：$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty (a_n \cos nx + b_n \sin nx)$
  - $a_n = \frac{1}{\pi} \int_{-\pi}^\pi f(x) \cos nx \, dx$
  - $b_n = \frac{1}{\pi} \int_{-\pi}^\pi f(x) \sin nx \, dx$

### 六、常微分方程（ODE）

#### 1. 一阶 ODE
- **可分离变量型**：$\frac{dy}{dx} = g(x)h(y) \Rightarrow \int \frac{dy}{h(y)} = \int g(x) dx$
- **齐次方程**：$\frac{dy}{dx} = \varphi(\frac{y}{x})$，令 $u = \frac{y}{x}$
- **一阶线性微分方程**：$\frac{dy}{dx} + P(x)y = Q(x)$，通解 $y = e^{-\int P dx} \left( \int Q e^{\int P dx} dx + C \right)$
- **伯努利方程**：$\frac{dy}{dx} + P(x)y = Q(x)y^n$，令 $z = y^{1-n}$ 转化为线性方程

#### 2. 二阶常系数线性ODE
- **齐次**：$y'' + py' + qy = 0$，特征方程 $r^2 + pr + q = 0$
  - 两个不等实根 $r_1, r_2$：$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$
  - 重根 $r$：$y = (C_1 + C_2 x) e^{rx}$
  - 共轭复根 $\alpha \pm i\beta$：$y = e^{\alpha x} (C_1 \cos \beta x + C_2 \sin \beta x)$
- **非齐次**：$y'' + py' + qy = f(x)$，通解 = 齐次通解 + 非齐次特解
  - 常用待定系数法求特解（自由项 $f(x)$ 为多项式、指数、三角或它们的组合）

### 七、空间解析几何与向量代数

- **向量点积**：$\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos \theta$
- **向量叉积**：$\vec{a} \times \vec{b} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ a_x & a_y & a_z \\ b_x & b_y & b_z \end{vmatrix}$，结果垂直于两者
- **平面方程**：$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$（点法式）
- **曲面方程**：$z = f(x, y)$，法向量 $\pm(-f_x, -f_y, 1)$
- **方向导数**：$\frac{\partial f}{\partial \vec{l}} = f_x \cos\alpha + f_y \cos\beta + f_z \cos\gamma$
- **梯度**：$\text{grad } f = (f_x, f_y, f_z)$，方向导数的最大值方向

### 八、常用公式速查

| 类别 | 公式 |
|------|------|
| 三角函数恒等 | $\sin^2 x + \cos^2 x = 1$，$\sec^2 x - \tan^2 x = 1$ |
| 和差化积 | $\sin A + \sin B = 2 \sin \frac{A+B}{2} \cos \frac{A-B}{2}$ |
| 倍角公式 | $\sin 2x = 2 \sin x \cos x$，$\cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$ |
| 勾股定理 | 空间点距离 $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$ |

### 总结建议

- **记忆方法**：公式不需要死记硬背，理解推导过程（如分部积分的 IRT 公式、格林公式的物理意义）会更容易掌握。
- **优先级**：对于考研/期末考试，**导数、积分、偏导数、重积分、格林/高斯/斯托克斯公式、级数审敛法、二阶 ODE 求解** 是考察最高频的模块。
- **工具**：建议整理个人公式卡片（Anki 或纸质卡片），配合例题练习，效果最好。
